## Setup Instructions
To run this project correctly, you must use a local development server because `books.html` uses the Fetch API to read `books.json`. Opening the HTML file directly (`file://`) will cause a CORS error.

1. Clone or download this repository to your local machine.
2. Open the project folder in a code editor like Visual Studio Code.
3. Start a local server (e.g., using the "Live Server" extension in VS Code).
4. Navigate to `books.html` to view the JSON data parsing.
5. Navigate to `jquery-dom.html` to view the jQuery DOM manipulations.
